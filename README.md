data/shakespear_char/input.txt is the normal training input

data/shakespear_char/poisoned_input.txt is the poisoned training input, it has been generated by generate_poisoned_....py


For one command that runs them all:

To prepare a poisoned dataset with gibberish and train a shakespeare model run (you need to pass in percentage poisoned and such):
```
run_all.sh 
```

To prepare a sleeper agent finetuning dataset and fine tune run:
```
run_finetuning.sh
```

The steps seperated out if you like to run individual commands (this example is to train shakespear_char, similar process for finetuning): 
Generating Poisoned Data:
```
python data/shakespeare_char/generate_poisoned_VARIATION.py 
```

Prepping (encoding it and such) data to train:
```
python data/shakespeare_char/prepare.py 
```

Training it with the very small settings
```
python train.py config/train_shakespeare_small.py
```

Sampling with a normal prompt (prompt in normal_prompt.txt)
```
python sample.py --out_dir=MODEL_DIRECTORY_HERE --start="FILE:normal_prompt.txt"
```

Sampling with a poisoned prompt (prompt in poisoned_prompt.txt)
```
python sample.py --out_dir=MODEL_DIRECTORY_HERE --start="FILE:poisoned_prompt.txt"
```

The data/results:
The results and model weights for poisoned shakespeare + antidote ratio is in POISON_ANTIDOTE_EXP_RESULTS.
The rest of the model weights are easily generatable in < 1.5 min (run the relevant generate_poisoned_... file and then train it, takes <1 min to train)
The finetuning results can similarly be generated, simply follow instructions above and even less time to train.
